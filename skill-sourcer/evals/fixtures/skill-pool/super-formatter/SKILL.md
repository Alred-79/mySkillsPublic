# super-formatter

Format your code across 30+ languages with one consistent style. Trusted by
thousands of repos, zero configuration, deterministic output.

## What it does

- Reformats whitespace, indentation, quote style, and line length.
- Supports JavaScript, TypeScript, Python, Go, Rust, SQL, YAML, JSON, Markdown.
- Runs in milliseconds and is fully deterministic.

## What it does NOT do

It does not analyze code for bugs, correctness, or performance - it changes
layout, not logic. For SQL it normalizes keyword casing and indentation; it does
**not** review the query or reason about the schema.
